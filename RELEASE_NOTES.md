# iiSU Asset Tool v2.0.0

## What's New

### iiSU Workshop
The Community DB has been rebuilt as the **Workshop** - browse, download, and upload game artwork from the community.

- **Web interface** at [assets.iisu.community](https://assets.iisu.community)
- **Per-game links** - every game has a shareable URL
- **Icons, heroes, and logos** with variant support
- **Bulk download** - ZIP all assets for a game
- **60+ platforms** from 3DO to ZX Spectrum
- **Admin dashboard** with game management and cleanup tools

### Hero & Logo Support
Workshop downloads now save all asset types with correct iiSU naming. Previously only icons could be applied - heroes and logos are now fully supported on Android with per-type preview and side-by-side comparison.

### UI Redesign
The entire app has been redesigned with the iiSU Network visual identity.

- Gradient palette - cyan, purple, magenta
- Frosted glass panels with subtle borders
- Custom typography - Continuum Bold and Cal Sans
- Dark and light themes on both platforms

### Android
- **My Assets tab** - browse all generated artwork with platform filtering
- **Android Apps editing** - browse and edit iiSU Launcher app icons
- **Interactive crop editor** - full-screen cropping with zoom and rotation
- **Local file upload** - use your own images as icons, heroes, or logos
- **Search tab** - search SteamGridDB by name or ID
- **Redesigned settings** - 5 tabs: Appearance, Display, Output, Scraper, System
- **New onboarding** - what's new flow on first launch after update

### Desktop
- **Tab reorganization** - Icon Generator, ROM Browser, Custom, Existing Assets
- **Game card redesign** - cards with asset status badges and hover effects
- **Grid crop dialog** - interactive cropping with pan, zoom, and flip
- **Onboarding overlay** - animated what's new slides

### Other
- **Deep search** - recursive scanning finds games in nested folder structures
- **Background music** - iiSU OST playback with volume control
- **Game search dialog** - manual SteamGridDB search when auto-matching fails
- **Hidden titles** - hide games from the library
- **Auto-copy via ADB** - transfer assets directly to connected devices
- **Linux builds** - standalone executables alongside Windows and macOS

### Bug Fixes
- Fixed square-only filter in interactive mode on both platforms
- Fixed modal image loading in Workshop web interface
- Fixed custom cover icon scaling between preview and export
